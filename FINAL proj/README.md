# SPRAWL 

Sprawl is an interactive data visualization querying immigration data from the United Nations from 1990-2024. 
The dataset contains data on immigrant count from 100+ origin countries and regions to 8 main destination regions. 

SPRAWL allows the user to choose a origin, destination, and year, and then creates a particle system with one particle for each 10 000 people in the destination region from the selected origin. 

The program allows user choice using 2 dropdown lists and one year slider. 
When chosen, the particle system expands to a grid shape.

CONTROLS 

Scroll to zoom in and out 
Click screen to expand particles to grid, and click again to collapse them at mouse position. 
Use the origin select and destination select to choose regions, and the slider to choose a 5 year range. 

When selected, the details of the system including regions, year and approximate immigrant count are written at the bottom of the screen.
